# SHL Assessment Recommendation System

## Overview

This project is a conversational SHL assessment recommendation API built using:

- FastAPI
- Sentence Transformers
- FAISS Vector Search
- Semantic Retrieval

The system recommends relevant SHL assessments based on hiring requirements.

---

## Architecture

User Query
→ FastAPI
→ Semantic Embedding
→ FAISS Retrieval
→ SHL Assessment Recommendations
→ JSON Response

---

## Features

- Conversational recommendation API
- Semantic search using embeddings
- FAISS vector retrieval
- Grounded recommendations
- REST API endpoints
